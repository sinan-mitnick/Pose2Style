# Pose2Style

Pose2Style is a machine learning-based web application that recognizes dance forms from uploaded videos using human pose estimation and computer vision techniques.

## Features
- Upload dance videos
- Human pose estimation using MediaPipe
- Dance classification using XGBoost
- Confidence score visualization
- Timeline of predictions
- Best-frame extraction

## Tech Stack
- Python
- Flask
- MediaPipe
- XGBoost
- OpenCV
- HTML
- CSS
